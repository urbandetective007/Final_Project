EXCEL ATTACHMENT TO GMAIL DRAFT — MANDATORY STEPS:
1. Save the workbook to disk first: wb.save(filepath)
2. Verify it is a valid ZIP:
   import zipfile
   with zipfile.ZipFile(filepath, 'r') as z:
       assert z.testzip() is None, "Excel file is corrupted"
3. Read it back in BINARY mode only:
   with open(filepath, 'rb') as f:
       raw_bytes = f.read()
   assert len(raw_bytes) > 0, "File is empty"
4. Encode to base64:
   import base64
   b64 = base64.b64encode(raw_bytes).decode('ascii')
5. Pass to the Gmail draft tool:
   content  = b64
   filename = "<the xlsx filename>"
   mimeType = "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"

NEVER read the file in text mode ('r'). NEVER encode from a BytesIO buffer without saving to disk first.
