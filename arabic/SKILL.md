# חיפוש בערבית

משלים את `business-address-lookup`. הסקיל ההוא מחפש בעברית ובאתרים ישראליים (b144, d.co.il, easy).
במזרח העיר רוב העסקים מופיעים ברשת רק בערבית (Google Maps, פייסבוק, מדריכים ערביים), ולכן שם החיפוש בערבית
הוא **העיקר** ולא תוספת.

כל הכללים של `business-address-lookup` נשארים: כתובת אחת בכל פעם, `tavily_extract` לכל ממצא, רחוב **ומספר בית**
תואמים בדף, אסור דף קטגוריה, אין טלפון מומצא. הקובץ הזה משנה רק **את השפה ואת השאילתות**.

## שלב 1 — בחירת מצב, לפני החיפוש של כל כתובת

בחר אחד משלושת המצבים. הסימנים הם הנחיה, לא רשימה סגורה — **ההחלטה בשיקול שלך**.
כתוב את המצב והסיבה בדיווח ✅ של הכתובת (למשל `מצב: ערבית — שכונה בית חנינא`).

| מצב | מתי | החיפושים לכתובת |
|---|---|---|
| **עברית** | רחוב מגורים בשכונה יהודית, בלי שום סימן לעסק ערבי | 6 החיפושים של `business-address-lookup`, כמו היום. אין חיפוש בערבית. |
| **מעורב** | רחוב עם פוטנציאל לעסק ערבי: רחוב מסחרי או ראשי בקו התפר או ליד שכונה ערבית (למשל הנביאים, שכם, שבטי ישראל, אזור התעשייה ואדי ג'וז, רחובות ליד שער שכם ושער הפרחים), או שהחיפוש בעברית כבר החזיר תוכן בערבית בכתובת | 6 החיפושים בעברית + 2–3 השאילתות הראשונות בערבית |
| **ערבית** | הרחוב במזרח העיר (ראה "שכונות" למטה), **או** ששם הרחוב הוא שם ערבי בכתיב עברי — גם כשהשכונה ריקה | 4–5 שאילתות בערבית (העיקר) + 2 בעברית ליתר ביטחון: `site:b144.co.il "<כתובת>"` ו-`site:d.co.il "<כתובת>"` |

**שכונות (רשימה מנחה, השמות כמו בעמודה B של `Adresses.xlsx`):**
בית חנינא, ג'בל מוכבר, צור באחר, א-טור, בית צפאפא, שועפאט, עיסוויה, ראס אל-עמוד, וואדי אל-ג'וז, כפר עקב,
סילואן, באב א-זהרה, ענתא, שיח' ג'ראח, וולג'ה, העיר העתיקה (הרבעים המוסלמי והנוצרי; הרובע היהודי — "עברית").

**שם רחוב ערבי בכתיב עברי** — סימנים: "אל-" / "אל " / "א-" בתוך השם, "סמ" (סמטה), "אבו", "אבן", "בן" + שם ערבי, "ואדי",
"ראס", "באב", "שיח'", "ג'בל", "חי", "עין", או שם שהוא בבירור ערבי (למשל "ראבעה אל עדוויה", "תקי אל-דין", "אל-מוסטפא").

**שינוי מצב באמצע כתובת מותר:** אם ב"עברית" התוצאות מראות תוכן בערבית בכתובת — עבור ל"מעורב".
אם ב"ערבית" כל התוצאות בעברית — השלם את 6 החיפושים בעברית.

## שלב 2 — שם הרחוב בערבית

תעתק את שם הרחוב מהכתיב העברי לערבית. רוב שמות הרחובות במזרח העיר הם תעתיק עברי של שם ערבי, ולכן החזר אותם לכתיב המקורי:

| ב-`Adresses.xlsx` | בערבית |
|---|---|
| ראבעה אל עדוויה | رابعة العدوية |
| תקי אל-דין | تقي الدين |
| סמ8 (סמטה 8) | زقاق 8 |
| ואדי אל-ג'וז | وادي الجوز |
| שועפאט | شعفاط |

שמור טבלה "רחוב → ערבית" לאורך הריצה, כדי שלא לתעתק את אותו רחוב פעמיים ולהשתמש בתעתיק אחיד.
שם השכונה בערבית לשאילתות: בית חנינא → بيت حنينا, ג'בל מוכבר → جبل المكبر, צור באחר → صور باهر, א-טור → الطور,
בית צפאפא → بيت صفافا, שועפאט → شعفاط, עיסוויה → العيساوية, ראס אל-עמוד → راس العامود, וואדי אל-ג'וז → وادي الجوز,
כפר עקב → كفر عقب, סילואן → سلوان, באב א-זהרה → باب الزاهرة, ענתא → عناتا, שיח' ג'ראח → الشيخ جراح, העיר העתיקה → البلدة القديمة.

## שלב 3 — השאילתות בערבית

לפי הסדר. ב"מעורב" — 2–3 הראשונות בלבד; ב"ערבית" — 4–5.

**בכל שאילתה: המילה `شارع` לפני שם הרחוב, ושם השכונה בערבית.** רבים מהרחובות במזרח העיר קרויים על שם דמויות
היסטוריות (الإمام الشافعي, عثمان بن عفان, الحجاج بن يوسف). חיפוש של שם הרחוב לבד מחזיר מאמרי היסטוריה ולא עסקים
(נבדק ב-21.10.2026). אם אין שכונה בעמודה B — `القدس` במקומה.

1. `"شارع <רחוב בערבית>" <מספר> "<שכונה בערבית>"`
2. `عيادة طبيب محامي صالون "شارع <רחוב בערבית>" "<שכונה בערבית>"` — הקטגוריות המועדפות של `business-address-lookup` בערבית
3. `"شارع <רחוב בערבית>" "<שכונה בערבית>" القدس محل شركة مكتب`
4. `"<רחוב בערבית>" "<שכונה בערבית>" site:facebook.com`
5. `"شارع <רחוב בערבית>" "<שכונה בערבית>" هاتف عنوان` — דפי מדריך עם טלפון וכתובת

תוצאה שעוסקת בדמות ההיסטורית ולא ברחוב — לא ממצא; אל תחלץ אותה.

## שלב 4 — אימות

בדיוק כמו `business-address-lookup` (שלב ג): מוצאים את הדף הייעודי של העסק ומחלצים אותו (`tavily_extract`), והדף חייב
להכיל את **שם הרחוב וגם את מספר הבית** התואמים לכתובת מ-`Adresses.xlsx`.
- הרחוב יכול להופיע בערבית, בעברית או באנגלית — כל עוד ברור שזה אותו רחוב.
- מספר בכתיב ערבי-הודי (`٤١`) = 41.
- **אין מספר בית תואם בדף — העסק לא נכנס לדוח**, גם אם הרחוב נכון. זה נפוץ במזרח העיר, ולא מוותרים על הכלל.

## שלב 5 — תרגום לעברית

**שם העסק** בעמודה "שם העסק": השם בעברית, ואחריו בסוגריים השם המקורי בערבית — למשל:
`מרפאת ד"ר אחמד ג'אבר (عيادة الدكتور أحمد جابر)`.
- **מילות תחום** — מתרגמים: عيادة → מרפאת, طبيب أسنان → רופא שיניים, محامي / مكتب محاماة → משרד עורכי דין,
  صالون → סלון, حلاق → מספרה, محاسب → רואה חשבון, صيدلية → בית מרקחת, روضة → גן ילדים, مطعم → מסעדה,
  ورشة → מוסך / סדנה, شركة → חברת.
- **שמות פרטיים ושמות משפחה** — מתעתקים לפי הטבלה:

| ערבית | עברית | | ערבית | עברית |
|---|---|---|---|---|
| ح | ח | | ث | ת' |
| خ | ח' | | ذ | ד' |
| ع | ע | | ض | צ' |
| غ | ע' | | ظ | ט' |
| ج | ג' | | ق | ק |
| ص | צ | | ة (בסוף מילה) | ה |
| ال | אל- | | | |

  שמות נפוצים — כתיב קבוע: محمد → מוחמד, أحمد → אחמד, محمود → מחמוד, عبد → עבד, عبد الله → עבדאללה, يوسف → יוסף,
  إبراهيم → איברהים, حسن → חסן, علي → עלי, خليل → ח'ליל.
- **סוג עסק** — בעברית, כמו בשאר הדוח.
- **כתובת** — הכתובת מ-`Adresses.xlsx` בדיוק, לא הכתובת מהדף.
- **טלפון ופרטים אחרים** שמופיעים רק בערבית — מתרגמים לעברית בטיוטת המייל; בדוח אין עמודה נוספת.

אחרי התרגום — אותה בדיקה של `known_businesses.py check` כמו כל עסק אחר. הסקריפט מאחד תעתיקים שונים
("מוחמד" = "מחמד", "אלחוסייני" = "חוסייני"), והחלק בערבית שבסוגריים לא מונע התאמה לעסק שכבר רשום בעברית בלבד.

## לטיוטת המייל

- כמה כתובות נסרקו בכל מצב (עברית / מעורב / ערבית).
- כמה עסקים נמצאו בחיפוש בערבית, וכמה מהם החיפוש בעברית לא מצא.
- עסקים בערבית שנפסלו רק כי לא היה מספר בית — שם, רחוב, קישור (כדי שאפשר יהיה לבדוק בשטח).
