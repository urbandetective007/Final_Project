# שיוך שכונה לכל כתובת — `tools/neighborhoods`

## המטרה

הסוכן סורק רשימת כתובות בירושלים ומחפש בהן עסקים. בדוח שהוא מפיק יש עמודת **שכונה**, והיא חייבת להיות שם אחד
מתוך הרשימה הסגורה של הסוכן (`data/jerusalem_neighborhoods.json` בריפו Arnona_Agent). ערך שאינו ברשימה נמחק בהעלאה ל-Supabase.

הכלי הזה מקבל קובץ כתובות ומחזיר את אותו קובץ עם **שתי עמודות בלבד**: `רחוב` (הכתובת המקורית) ו-`שכונה` (שכונה אחת מהרשימה, או ריק).
את הקובץ הזה הסוכן קורא: הוא מתחיל מהשכונה שבקובץ ומאמת אותה באינטרנט רק כשנמצא עסק בכתובת.

הכלי **זוכר כל החלטה**, כך שבעדכון הבא של רשימת הכתובות רק כתובות חדשות דורשות עבודה — עדכון לוקח דקות, לא שעות.

הכלי נמצא בשני הריפו (Final_Project ו-Arnona_Agent) באותה גרסה. מי שמעדכן אותו באחד — שיעתיק גם לשני.

## איך מריצים (עדכון רשימת כתובות)

```bash
pip install openpyxl
python3 tools/neighborhoods/assign_neighborhoods.py "<קובץ הכתובות החדש>.xlsx" Adresses_new.xlsx
```

- קובץ הקלט: הכתובות בעמודה הראשונה ("רחוב מספר"), עם או בלי שורת כותרת.
- בסוף הריצה מודפס סיכום: כמה כתובות הוכרעו בכל שיטה, אילו רחובות לא נמצאו ברשימת העירייה, ואילו שמות שכונה לא הותאמו לרשימה.
- הריצה מעדכנת את קבצי הזיכרון ב-`data/` — **צריך לעשות להם commit יחד עם הקובץ החדש.**

**ב-Final_Project (הרוטינה Game):** מחליפים את `Adresses.xlsx` בקובץ שיצא, מעבירים את הישן ל-`archive/`,
ומאפסים את `index` ל-`index = 0` אם סדר הכתובות השתנה.

אפשרויות:
- `--no-cache` — מתעלם מהחלטות קודמות ומחליט מחדש (למשל אחרי שינוי בקובץ העירייה). התוצאות החדשות נשמרות בזיכרון.
- `--no-geocode` — בלי פנייה למפה; רחוב שמשויך לכמה שכונות מקבל את הנפוצה מביניהן.

## איך כל כתובת מוכרעת (הראשון שמתאים קובע)

1. **תיקון ידני לכתובת** — `data/overrides.json`, תחת `addresses`.
2. **החלטה מריצה קודמת** — `data/address_cache.csv`.
3. **תיקון ידני לרחוב** — `data/overrides.json`, תחת `streets`. ערך בצורה `"A / B"` מצמצם את הרחוב לשתי האפשרויות האלה, והמפה מכריעה ביניהן.
4. **רשימת הרחובות של העירייה** — `data/municipal_streets_2020.xlsx` (רחוב ← שכונה, מ-17.11.2020).
   התאמה מדויקת, אחר כך אחרי ניקוי כתיב (גרש, מקף, "סמ", "הרב", "שד", סדר מילים), ואחר כך כתיב קרוב בשמות ארוכים.
   שמות השכונות של העירייה מתורגמים לשמות ברשימה של הסוכן (`aliases` שבקובץ הרשימה + `name_map` שב-`overrides.json`).
5. **רחוב שמשויך לכמה שכונות** — הכתובת מאותרת ב-OpenStreetMap (אותה שיטה שהאתר של הסוכן משתמש בה):
   - אם OSM רושם במיקום הזה שכונה שהיא אחת האפשרויות של הרחוב — היא נבחרת.
   - אחרת — האפשרות שמרכז השכונה שלה הכי קרוב (`data/jerusalem_neighborhood_centers.json` ב-Arnona_Agent).
   - כתובת שלא נמצאה במפה — האפשרות שמופיעה בהכי הרבה שורות ברשימת העירייה.

   המיקומים נשמרים ב-`data/geocode_cache.jsonl`, כך שכתובת מאותרת פעם אחת בלבד. OSM מאפשר בקשה אחת בשנייה — 1,000 כתובות חדשות כאלה ≈ חצי שעה.
6. **רחוב שלא ברשימת העירייה** — השכונה נשארת ריקה. הסוכן משלים אותה מהאינטרנט כשהוא מוצא עסק בכתובת.

## תיקונים ידניים — `data/overrides.json`

| מפתח | מה זה | דוגמה |
|------|-------|-------|
| `name_map` | שם שכונה של העירייה / OSM ← שם ברשימה של הסוכן | `"גבעה צרפתית": "הגבעה הצרפתית"` |
| `streets` | רחוב (כפי שהוא כתוב בקובץ הכתובות, בלי מספר בית) ← שכונה | `"רשבג": "קטמון"` |
| `addresses` | כתובת מלאה ← שכונה (גובר על הכול) | `"תחכמוני 30": "מקור ברוך"` |

כשהסוכן מתקן שכונה (הוא מפרט את התיקונים בטיוטת המייל) — כדאי להוסיף את התיקון ל-`addresses`, ולהריץ שוב.
שם שכונה בתיקון חייב להיות בדיוק כמו ברשימה של הסוכן.

## הקבצים

| קובץ | תוכן |
|------|------|
| `assign_neighborhoods.py` | הכלי |
| `data/municipal_streets_2020.xlsx` | רשימת רחוב ← שכונה של עיריית ירושלים (17.11.2020) |
| `data/overrides.json` | תיקונים ידניים (כולל ההשלמות שנעשו ביד באוקטובר 2026) |
| `data/address_cache.csv` | כתובת ← שכונה, לכל כתובת שכבר הוכרעה |
| `data/geocode_cache.jsonl` | מיקום ב-OSM לכל כתובת שאותרה במפה |

רשימת השכונות ומרכזי השכונות נקראים מ-`data/` של Arnona_Agent: מקומית כשהכלי רץ בתוך Arnona_Agent, ומ-GitHub (ענף `main`) כשהוא רץ ב-Final_Project.

## מגבלות

- רשימת העירייה היא מ-2020 — רחובות חדשים יותר לא נמצאים בה ונשארים בלי שכונה. אם תושג גרסה עדכנית — מחליפים את הקובץ ומריצים עם `--no-cache`.
- גבולות השכונות ב-OSM לא תמיד זהים לגבולות העירייה; לכן OSM רק מכריע **בין** האפשרויות שהעירייה נותנת לרחוב, ולא מוסיף שכונה חדשה.
- ההכרעה לפי מרכז שכונה קרוב היא הערכה. היא מספיקה כנקודת פתיחה, והסוכן מאמת באינטרנט כשנמצא עסק.
