- `game-routine/prompt_2026-10-21.txt` — the live prompt (same as `prompt_2026-10-20.txt` without the python3 fix block, which was never pasted into the routine) plus the Arabic search: before every address the agent chooses a search mode (Hebrew / mixed / Arabic) per `arabic/SKILL.md`; in Arabic mode most searches are in Arabic and the business name is written in Hebrew with the Arabic original in parentheses. It also skips addresses with a placeholder house number (none, 0, 999, 1000 and above — 714 addresses) without any search.
- `game-routine/prompt_2026-10-21_connector.txt` — the same prompt with the Tavily connector instead of the API keys (`tools/tavily`): use it once the paid Tavily plan is connected to the routine.
- `game-routine/prompt_2026-10-25.txt` — the live prompt (Tavily connector). Three changes:
  1. **Address match:** "גבוה" only when the address on the business's page is a full match for the address from `Adresses.xlsx`, otherwise "דרוש בדיקה". Every link is written `URL (address on the page)`. This came after businesses on רחוב מאה שערים were reported at "ב אונגר מאה שערים N" (בתי אונגרין). See `business-address-lookup.skill` sections ב.0, ד and ה.
  2. **Exhaustive search:** instead of exactly 6 searches, a base set of 12 (directories, Facebook / Instagram / LinkedIn, maps, professional directories, private sites), then expansion rounds until 2 rounds in a row bring nothing new, and up to 3 links per business.
  3. **The results always reach the mail:** the draft is created with the Excel before the first search and updated after every address. The index is pushed every 3 addresses and only past addresses that are already in the draft. Stop limits are counted rather than estimated (12 addresses / 120 Tavily calls / 100 new businesses). A run that is cut still leaves a draft with everything found up to that point, and the 30,000-token limit is gone. To go back, paste `prompt_2026-10-21_connector.txt` into the routine.
